## 二维码

- `qr/profile.svg` 和 `qr/profile.png`：使用 Python `qrcode` 标准编码生成，内容为 **`https://lozic7.com`**，M 级纠错，四模块留白。
- 二维码是个人网站入口，不是 QQ 登录码，不收集账号或密码。

## 版本与使用边界

- macOS 图标中的 Safari、Messages、Terminal、Calendar、FaceTime、Calculator、Phone、Weather、Contacts、Notes、Photos 均直接取自 Apple 官方 macOS 27 User Guide 的 400 × 400 页首 PNG。
- Finder 为 macOS Tahoe 26；系统设置沿用 Big Sur System Preferences 的高分辨率图形；两款壁纸为 Sequoia。按需求允许混用真实旧版素材，未声称这一组全部属于 macOS 27。
- 系统设置的 ICNS 与两款壁纸来自注明原系统版本的第三方归档；未取得 Apple 下载签名或系统包哈希，因此不能将托管仓库称为 Apple 官方资源发布站。
- QQ 图标取自用户已安装的 Windows QQ NT；保留企鹅的真实品牌图形，但不是从 Mac 版 QQ 提取。
- Gmail 与 GitHub 使用其网页品牌标志，不伪装成不存在的 Mac Gmail 客户端或 GitHub Desktop。
- `wallpapers/original.jpg` 是用户要求保留的旧版 Unsplash 壁纸，与两款 Sequoia 深浅壁纸分别提供；未推断摄影师或作品名称。
- QQ 只做 ICO 最大图层提取、System Preferences 只做 ICNS 最大图层转为无损 PNG；其余图标和壁纸保留下载原始字节，无重绘／重新压缩。
- Apple、Tencent、Google、NetEase、GitHub、Microsoft 图标与壁纸的名称、商标和版权归各自权利人；来源页面的具体授权与品牌使用说明仍适用。个人桌面为独立网页项目，不表示得到这些公司的认可。

## 校验

- 全部本地图像可由 Pillow 解码；SVG 已按 XML 解析。
- `qr/profile.png` 已通过独立 ZXing 解码器回读，结果严格等于 `https://lozic7.com`。
- 完整原始 URL、文件大小、尺寸和 SHA-256 校验值另见 `icons/source-manifest.json`。
