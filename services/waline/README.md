# Lozic 留言服务

这是与静态桌面分开部署的 Waline 服务。桌面不需要 Node 构建依赖；只有留言服务安装本目录的依赖。

## 本地使用

需要 Node 22.12 或更新的 Node 22。

```powershell
cd services/waline
npm ci
npm start
```

- 地址：`http://127.0.0.1:8360`。
- 后台：`http://127.0.0.1:8360/ui`。
- 持久测试数据在被 Git 忽略的 `.data/waline.sqlite`，启动时只在文件不存在时初始化，不会覆盖现有库。
- 本地浏览器访问桌面时自动连接此服务，并清楚标注“本地测试留言”。
- 本地首次注册的管理账号将成为管理员，由你在后台注册；此账号只属于本地测试数据库。
- 本地环境为了独立调试关闭了外部反垃圾请求、发布频率限制及审核。正式部署使用 `.env.example` 中的发布限制，不复制本地调试配置。
- 本地服务只监听 `127.0.0.1`，不是公开网络服务。

## Vercel 上线

参见仓库的 [完整部署说明](../../docs/DEPLOYMENT.md)。Vercel 为留言服务另建项目，Root Directory 选择 `services/waline`，配置 PostgreSQL 和环境变量；不要在 Vercel 用 SQLite 临时文件保存正式留言。

服务固定 `@waline/vercel` 1.42.0，并提交对应锁文件。当前检索到的更新版本依赖存在发布问题，选择依据见 [接入研究](../../docs/WALINE_INTEGRATION_RESEARCH.md)。升级时同时核对接口、匿名留言和数据库兼容性。

## 本站规则

- 昵称 1–24 个 Unicode 字符，全部存储正文（含歌曲标记）1–1000 个字符。
- 不要求邮箱、不要求登录。普通访客不能伪造管理员身份。
- 回复必须关联同一面留言墙中已公开的父留言与根留言。
- 正式墙标识：`personal-mac/guestbook`；测试墙标识：`personal-mac/guestbook-test`。
- 本站前端把留言作为安全文本渲染，只识别站内允许的曲目引用，不执行留言中的 HTML。
- 站长通过 Waline 后台回复、审核和删除；管理凭据不要写进前端配置。

## 必要的接口检查

在仓库根目录运行 `npm run test:guestbook`。这会往本地测试墙写入明确标注的测试留言；验证跨客户端读写、回复、身份伪造拒绝、长度与父记录校验。该命令只连接 `127.0.0.1:8360`，不会向线上服务提交测试内容。
